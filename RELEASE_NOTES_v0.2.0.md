# Relativistic Spaceship Viewer 0.2.0

Local release package prepared for review. Not published to GitHub.

The original prototype is refurbished into a Qt desktop application while
keeping its instantaneous special-relativistic sky model accessible and tested.

- Precise beta/gamma controls, rapidity slider, independent camera/velocity
  heading, configurable FOV, synchronized rest/moving comparison, and an object
  inspector with a labeled wavelength-shift example.
- Explicit catalog import units, row rejection reports, missing-value handling,
  source/frame/epoch provenance, and offline demo operation.
- Portable JSON scenes, 4K PNGs, SVG/PDF figures, numeric arrays, and source/runtime
  hashes. Scientific exports can be reopened and numerically reproduced.
- Per-user Windows installer, stable Start menu launcher, versioned releases,
  checked updates activated after the app closes, previous-build rollback, and
  uninstall that preserves user-added scientific files.
- Directional tests, original-scene references, Qt integration, export replay,
  deployment failure handling, and local packaged-runtime checks.

The original catalog values and small JPEGs are preserved. The directional model
does not simulate a finite voyage, proper motion, acceleration, or retarded-time
rendering. Color and D³ marker brightness remain illustrative; no calibrated
photometry or uncertainty propagation is added. The sparse demo is not
magnitude-complete, its original measurement/frame/epoch provenance is
unspecified, and M42 remains an extended-object point placeholder.

The local Windows assets are unsigned. Local install tests do not certify a
clean second computer or a publicly hosted update. No actual release update can
be downloaded until the assets are explicitly published.
